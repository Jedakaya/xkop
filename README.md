# xkop

Маршрутизатор трафика для OpenWrt на движке Xray-core.

Задача роутера — **распределять** трафик, а не гнать его весь в туннель.
Заблокированное идёт через прокси, остальное напрямую, и решение принимается
по спискам доменов и подсетей, а не по принципу «всё или ничего».

## Состояние

Начата реализация. Принятые решения — в `docs/`.

Готова команда `stats`: читает метрики Xray и отдаёт нормализованный JSON
для дашборда — трафик по каждому исходящему, распределение по ролям
и состояние узлов. Контракт описан в `docs/stats.md`.

## Отличия

**Канарейка** — механизм, который сам выясняет, подменяет ли провайдер
DNS-ответы, и какой именно адрес он подсовывает вместо настоящего. Выученную
заглушку роутер дальше отбраковывает автоматически, откуда бы она ни пришла.

Собственная реализация на Xray-core: XHTTP, Reality и Hysteria2 без сторонних
форков движка. Подписки забираются несколькими User-Agent и сливаются в один
пул, потому что разные клиенты получают от панелей дополняющие наборы серверов.
Несколько подписок объединяются, мёртвые серверы уходят в карантин, а не
выбрасываются.

Отдельная панель для конечного пользователя, где нет ничего кроме подписки
и выбора маршрута.

Списки доменов и подсетей берутся из
[itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains).
